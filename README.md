# Invitación boda - Pablo & Jessica

Proyecto de invitación web en React + Vite, adaptado con la información de Pablo Carranza Cruz y Jessica Noemí Muñoz Balderas.

## Datos incluidos
- Portada e intro personalizadas
- Historia con 3 fotografías
- Cuenta regresiva al 11 de diciembre de 2027 (tomado como fecha principal del evento)
- Ceremonia y celebración con ubicación
- Hospedaje en Hotel Las Hadas
- Código de vestimenta
- Confirmación de asistencia visual

## Nota importante
- La **fecha principal** usada en la invitación es **11 de diciembre de 2027**, ya que la estancia del hotel es del 10, 11 y 12 de diciembre de 2027 y no se indicó otra fecha distinta para la boda.
- El audio actual sigue tomando el archivo `src/assets/audio/musica.mp3`. Si quieres usar la canción **"Felicidad"**, solo reemplaza ese archivo por tu MP3 con el mismo nombre.

## Cómo abrir el proyecto
1. Instala **Node.js**.
2. Abre una terminal dentro de la carpeta del proyecto.
3. Ejecuta:

```bash
npm install
npm run dev
```

4. Abre en tu navegador la URL que te aparezca en la terminal, normalmente:

```bash
http://localhost:5173/
```

## Para generar versión de producción
```bash
npm run build
```
